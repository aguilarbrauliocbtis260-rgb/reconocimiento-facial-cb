01

Identificación rápida y automatizada

En algunos espacios es necesario identificar rápidamente a una persona. Cuando este proceso se realiza únicamente mediante observación humana puede requerir tiempo y depender de la persona encargada.

Además, cuando existe una gran cantidad de personas, realizar la identificación de manera manual puede resultar menos práctico.

01

¿Qué problema se busca resolver?

Facilitar la identificación de personas mediante una herramienta digital que utilice Inteligencia Artificial para analizar una imagen.

02

La solución

IA

Uso de Inteligencia Artificial

La Inteligencia Artificial permite desarrollar soluciones capaces de analizar información y generar resultados automáticamente.

Para resolver esta problemática se desarrolló una aplicación web utilizando un modelo de Inteligencia Artificial entrenado mediante Teachable Machine.

El modelo aprende a reconocer diferentes clases a partir de imágenes proporcionadas durante su entrenamiento. Posteriormente, se integra en una página web mediante JavaScript para utilizar la cámara del dispositivo.

De esta manera, la aplicación permite demostrar una solución práctica utilizando Inteligencia Artificial dentro de una página web.

03

¿Qué hace la aplicación?

La aplicación utiliza un modelo creado y entrenado en Teachable Machine para analizar la imagen capturada por la cámara y determinar a qué persona corresponde.

01

Entrenamiento

El modelo se entrena utilizando imágenes de las personas que se desean identificar.

02

Análisis

La cámara captura una imagen y el modelo analiza sus características para realizar una predicción.

03

Resultado

La aplicación muestra la persona identificada junto con el porcentaje de confianza obtenido.
